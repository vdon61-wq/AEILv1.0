# AEIL Benchmark v1.0.0

This directory contains the initial 60-case benchmark.

- `core/tests.json` — 20 tests
- `safety/tests.json` — 20 tests
- `adaptation/tests.json` — 10 tests
- `agents/tests.json` — 10 tests

These cases are a starting public benchmark, not a statistically complete representation of all human interaction contexts.
