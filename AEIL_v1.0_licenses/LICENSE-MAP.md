# AEIL v1.0 — License Map

Use the following mapping when adding files to the repository.

### Documentation / specification

Use:

`CC-BY-4.0`

Typical files:
- `README.md`
- `SPECIFICATION.md`
- `PRINCIPLES.md`
- `TAXONOMY.md`
- `SCORING.md`
- `SEVERITY.md`
- `SAFETY.md`
- `BENCHMARK.md`
- `docs/*`
- `audits/*.md`
- `certification/*.md`

### Public benchmark content

Use:

`CC-BY-4.0`

Typical files:
- `benchmark/core/*`
- `benchmark/safety/*`
- `benchmark/adaptation/*`
- `benchmark/agents/*`

### Code and machine-readable implementation

Use:

`Apache-2.0`

Typical files:
- source code;
- SDKs;
- command-line tools;
- test runners;
- JSON schemas;
- implementation utilities.

### Project branding

Use:

`TRADEMARK.md`

Do not treat the copyright license as permission to use AEIL branding.

### Certification

Use:

`CERTIFICATION.md`

Certification status must never be inferred solely from the license.

## Important

If a future benchmark includes third-party datasets, prompts, images, articles, or other
external materials, each such component must be reviewed and licensed separately.
Do not assume the AEIL benchmark license automatically covers third-party content.
